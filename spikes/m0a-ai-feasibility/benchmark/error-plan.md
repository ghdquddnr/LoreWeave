# 오류 · 함정 배치표

> 평가 입력에 넣지 않는다. 본문 작성 후 이 표를 바탕으로 `ground-truth.json`(정확한 원문 구간 포함)을 만든다.

## 정의

- **대상 화(target)**: 오류가 들어가는 화. 평가는 "N화를 1~N-1화와 비교"하므로 오류는 대상 화에서만 탐지 대상이다.
- **근거 화(source)**: 오류와 충돌하는 canon이 확립된 화.
- **거리**: target − source. near ≤ 2 / mid 3~4 / far ≥ 5.
- **명시도**: L1 직접 모순 / L2 표현이 바뀐 모순 / L3 계산·추론이 필요한 모순.
- **분할**: 유형마다 dev 1개, test 2개 (dev 10 / test 20). 함정은 dev 3 / test 7.

## 오염 방지 규칙

오류는 해당 화 한 곳에서만 canon을 어긴다. 이후 화는 다시 canon을 따른다.
따라서 이후 화를 검사할 때 "앞서 삽입된 오류 구간"을 근거로 한 지적이 나올 수 있다.

- **Echo 규칙**: 예측의 근거(evidence)가 다른 오류의 대상 구간과만 겹치면 **echo**로 분류해 TP/FP 어디에도 넣지 않고 따로 집계한다.
- 본문 작성 시, 오류로 바뀐 사실은 이후 화에서 가능한 한 다시 언급하지 않는다 (이름처럼 피할 수 없는 경우 제외).

## 방해 설정

오류도 함정도 아니지만 모델 주의를 분산시키는 canon. 본문에 자연스럽게 반복 언급한다.

- 지현은 술을 못 마신다 (3화, 이후 회식 장면에서 일관되게 유지)
- 민수는 생각할 때 볼펜을 돌린다
- 미래전자 첫 제품 MP-1
