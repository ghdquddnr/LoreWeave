# 성능 측정 결과

- 생성: `pnpm perf` (자동 생성 파일). 실행 5회, 대상을 번갈아 실행
- 환경: AMD Ryzen 9 3900X 12-Core Processor × 24, RAM 32GB, Windows 10.0.19045
- Chrome 155.0.8059.85 / Electron 44.9.3 (Chromium 152.0.7977.167). production 빌드, 창 1400×900, StrictMode 없음
- 변환기: (c) 직접 작성 · C3 (로드 비교 표 제외). 원고: M0-A 챕터 반복 (C3라 빈 줄도 블록)
- 입력 지연: keydown 이벤트 시각 → 다음 프레임이 그려진 직후. 실행마다 40키 (영문 글자, Backspace, Enter) 60ms 간격
- 한글 IME 조합 입력은 자동화할 수 없어 여기 포함되지 않는다 (manual/CHECKLIST.md)
