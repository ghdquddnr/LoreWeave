## 결론

**detect-2 후보는 M9 기준 8(합성 원고 M4 회귀)을 충족하지 못했다.**

- M4 3회 중 m4-3이 test Recall 15/20으로, 회별 기준 17/20에 미달했다.
- 감독 지시대로 실제 원고 20화 2회는 **호출하지 않았다** (호출 0).
- 제품 판단 프롬프트는 detect-1 그대로다. 기준은 실행 뒤에 완화하지 않는다.

| 회 | test Recall (0.7 적용 뒤) | Precision | 화당 오탐 (÷14) | 판정 |
|---|---|---|---|---|
| m4-1 | 17/20 (85%) | 94.4% | 0.071 (1개) | 통과 |
| m4-2 | 18/20 (90%) | 100% | 0 | 통과 |
| m4-3 | **15/20 (75%)** | 93.8% | 0.071 (1개) | **미달** |
| 기준 8 | ≥ 17/20 | ≥ 85% | ≤ 0.3 | 세 회 모두 통과해야 함 |

## 실행

- **모델·프롬프트**: gpt-6-luna, detect-2-candidate.
- **설정**: 400개씩 나눠 검사, 묶음 동시 2, 출력 상한 16,000토큰, 요청마다 재시도 최대 1회.
- **원고**: M4 시험 원고 15화 중 검사 대상 14화(2~15화) × 3회. 저장된 분석으로 검사했고 다시 추출하지 않았다.
- **사전 대조** (호출 전, 3회 모두): 14/14화 일치, 묶음 14, 불일치 0.
  - M4 당시 평가기 출력이 남아 있지 않아 화·인용 순서 대조는 건너뛰었다 (`skipped: order`).
  - 원고 15화가 M0-A 벤치마크와 바이트까지 같은지 확인한 뒤 정답표를 썼다.
- **회차 상태**: m4-1·m4-2·m4-3은 완주했다. real-1·real-2는 시작하지 않았다.

## 회별 결과

확신도 0.7 미만으로 숨긴 결과는 세 회 모두 0개다. 그래서 필터 전후 값이 같다. 맞는 결과의 최저 확신도는 0.86~0.88이다.

| | m4-1 | m4-2 | m4-3 |
|---|---|---|---|
| 놓친 test 오류 | E02, E23, E26 | E23, E26 | E02, E20, E23, E26, E30 |
| 놓친 dev 오류 | E24, E25, E28 | E24, E25, E28 | E14, E24, E25 |
| 함정 오탐 (test 7개 중) | 0 | 0 | 0 |
| echo | 2 | 0 | 1 |
| 오탐 (평가기 unlabeled) | 1 (3화, 습관) | 0 | 1 (13화, 숫자) |
| retrieval / judge | 86.7% / 92.3% | 86.7% / 92.3% | 86.7% / 84.6% |

- **입력이 같다.** retrieval이 세 회 모두 86.7%다. 차이는 판단 단계의 회 간 편차다.
- **E23·E26은 세 회 모두 놓쳤다.** M0-A의 detect-1(B 전략, luna)도 놓친 오류다.
- **m4-1과 m4-3에서 놓친 것**: E02 (첫 만남)
- **m4-3에서만 놓친 것**:
  - E20: 날짜 간격 계산. M0-A detect-1 luna도 놓친 오류다
  - E30: 고소공포증 습관
- (정정, 2026-10-26: 처음에는 E02를 "m4-3에서만" 아래에 두었다. E02는 m4-1과 m4-3에서 모두 놓쳤다. 사례별 대조는 [`M9-FOLLOWUP.md`](M9-FOLLOWUP.md)에 있다.)
- **오탐 2개는 이 보고를 처음 쓴 시점에는 사람 검토 전이었다.** 평가기의 unlabeled를 그대로 오탐으로 셌다. 그 뒤 후속 판정을 마쳤다(`M9-FOLLOWUP.md` "정답표 밖 결과 2개"). 3화는 확정 오탐(잘못 읽음), 13화는 echo 성격의 오탐이다. 아래 수치는 바뀌지 않는다.
  - 3화 습관: "생각이 많아질 때마다"라는 습관 조건을 장면에 지나치게 적용했다.
  - 13화 지분 수치: 지분이 앞 화와 다르다는 것을 "설명 없는 변화"로 보고했다. 새 규칙 나("설명 없는 같은 속성 차이는 보고")가 이런 결과를 낳았을 수 있다. 원인은 확인하지 않았다.

## 비교

| | 회 | test Recall | Precision | 화당 오탐 |
|---|---|---|---|---|
| M4 제품 detect-1 (`M4-REPORT.md`) | 1 | 90% | 100% | 0 |
| M0-A B 전략 detect-1 luna (`results/summary.json`) | 3 | 평균 85%, 편차 10%p | 94.4% | 0.071 |
| **M9 detect-2 후보** | 3 | 85%, 90%, **75%** (평균 83.3%, 편차 15%p) | 93.8~100% | 0~0.071 |

- **detect-1에도 회 간 편차가 있었다.** M0-A detect-1 luna는 3회 평균 85%, 편차 10%p였다. 회별 기준 17/20을 한 회가 밑돌았을 수 있다.
  - 이것은 해석에 쓸 맥락일 뿐이다. 기준을 바꾸는 근거가 아니다.
  - detect-2의 m4-3(75%)은 M0-A detect-1의 범위보다 낮다.
- **실제 원고(M8 기준)와의 비교는 없다.** 실제 원고를 돌리지 않았다.

## 한계

- M4의 당시 평가기 출력이 없어 화·인용 순서 대조를 건너뛰었다. 나머지 기록 항목은 모두 대조했다.
- M8·M4 당시의 실제 요청 바이트는 기록이 없어 알 수 없다. 입력이 같다는 판단은 기록·재구성·불명을 구분한 대조에 근거한다.
- 3회는 편차를 판단하기에 적은 수다. 다만 기준 8은 "세 회 모두"이므로 판정은 미달이다.
