# M7 계획: 낮은 확신도 숨기기와 실제 원고 Recall

M7는 [M6](M6-REPORT.md)에서 남은 두 가지를 다룬다.

1. **오탐 줄이기**: 모델이 "모순이 아니다"라고 쓰고도 낸 결과처럼, 확신도가 낮은 결과를 화면에서 숨긴다.
2. **실제 문체에서 얼마나 찾는가**: M6는 정답표가 없어 Recall을 몰랐다. 실제 장편 복사본에 오류를 직접 심어 찾는 비율을 잰다.

- 확정한 선택 (2026-10-25, 사용자)
  - 범위: 확신도 기준값으로 숨기기 + 실제 원고에 오류를 심어 Recall 재기
  - 심기: Claude가 원문을 읽고 20화에 하나씩, 앞에서 정해진 설정과 부딪히게 문장을 고친다. 작가는 몇 개만 확인한다
- 원고 다루기는 M6와 같다. 원고, 오류를 심은 복사본, 심은 오류 목록(원문 인용이 들어간다), 결과는 저장소 밖에 둔다. 작품 이름과 인물 이름은 저장소에 적지 않는다.

## 1. 낮은 확신도 숨기기

- **기준값 정하기 (비용 없음)**: 이미 있는 결과로 기준값마다 Recall·Precision·화당 오탐을 본다.
  - M4: 15화 실행 결과 (`D:\LoreWeave-test`의 `ai.db`)
  - M5: 150화 `batch-400` 2회
  - M6: 실제 장편의 결과 7개와 판정
  - 합성 원고의 Recall을 떨어뜨리지 않는 가장 큰 값을 고른다. 0.5 안팎을 예상한다.
- **제품**
  - 기준값보다 낮은 결과는 저장은 하되 패널 목록과 개수에서 뺀다. "확신이 낮아 숨긴 결과 N개 [보기]"로 볼 수 있게 한다 (무시한 결과처럼).
  - 확신도는 모델이 정한 보조 정보라는 점은 그대로다 (INTENT §5). 숨긴 결과도 지우지 않는다.

## 2. 실제 원고에 오류 심기

- **복사본**: M6 원고 폴더(265화, 분석 결과 포함)를 저장소 밖에 통째로 복사한다. 복사본에만 오류를 심는다.
- **심는 곳**: M6에서 검사한 20화 (2, 16, 30, …, 265화)에 하나씩, 모두 20개.
- **심는 방법**
  - 원문을 읽고, 앞 화에서 분명히 정해진 설정 하나를 고른다.
  - 그 설정과 부딪히도록 이 화의 문장 하나를 최소한으로 고친다 (숫자 하나, 이름 하나, 관계 하나 등).
  - 바꾼 문장이 문맥상 자연스러워야 하고, 작품 안에서 설명될 여지(레벨업, 회상, 거짓말 등)가 없어야 한다.
- **종류와 거리**
  - 종류: M0-A의 10종류(나이, 이름, 직업·소속, 관계, 첫 만남, 사망 인물, 날짜·순서, 숫자·금액, 장소, 성격·습관)를 고르게 쓴다. 이 장르의 능력·아이템 설정도 포함한다.
  - 거리: 근거가 가까운 앞 화(10화 이내)인 것과 먼 앞 화(50화 이상)인 것을 섞는다.
- **정답표**: M0-A 형식(`ground-truth.json`)으로 저장소 밖에 쓴다. 바꾼 문장(target)과 근거 문장(sources)을 담는다. 함정(정당한 변화)은 심지 않는다.
- **도구**: `scripts/seed-errors.ts`
  - 원고 폴더를 복사한다.
  - 심을 목록(JSON: 화, 찾을 글, 바꿀 글, 종류, 근거)대로 고친다. 찾을 글이 그 화에 정확히 한 번 있어야 한다.
  - 정답표를 쓴다.
- **작가 확인**: 심은 20개 중 몇 개를 작가가 골라 "정말 모순인지" 확인한다.

## 3. 측정

- 복사본에서 고친 20화만 다시 분석하고(나머지 245화는 M6 분석 결과 그대로), 같은 20화를 제품 설정으로 검사한다.
- 결과를 M0-A 채점기로 채점한다 (복사본 폴더를 벤치마크 폴더로).
  - 심은 오류를 찾은 것: TP
  - 정답표에 없는 결과: 사람이 판정한다. M6처럼 원래 원고의 결과일 수 있다.
- 숨기기 기준값을 적용하기 전과 후를 함께 보고한다.

## 4. 성공 기준 (실행 전에 고정)

| 항목 | 기준 | 근거 |
|---|---|---|
| 기준값이 합성 원고 Recall을 떨어뜨리지 않음 | M4·M5에서 기준값 적용 전후 Recall 차이 0 | 숨기기는 오탐만 줄여야 한다 |
| 실제 원고 Recall (심은 오류, 기준값 적용 뒤) | ≥ 60% | M0-PLAN의 최소 기준 |
| 화당 오탐 (기준값 적용 뒤, 사람 판정) | ≤ 1 | M0-PLAN, M6와 같다 |
| 비용 | 이번 단계 합계 ≤ $0.5 | 예상 약 $0.25 |

- Recall이 기준에 못 미쳐도 단계는 끝낸다. 어떤 종류·거리를 놓치는지와 retrieval/judge 중 어디서 놓치는지를 보고서에 남긴다.

## 8. 위험

- **내가 심은 오류가 쉽거나 어렵게 치우칠 수 있다**: 오류를 고른 사람이 결과를 아는 상태가 아니도록, 심기를 마친 뒤에 검사한다. 종류·거리를 미리 고르게 나눈다.
