# M8 계획: 추출을 촘촘하게 (긴 화를 나눠 추출)

M8는 **긴 화에서 사실이 덜 뽑히는 문제**를 고친다. [M7](M7-REPORT.md)에서 실제 원고에 심은 오류의 절반은 근거가 검사에 들어가지 않아 놓쳤다.

## 1. 왜 (진단)

처음에는 "인물이 아닌 대상(마법·아이템·장소)의 사실을 근거로 고르기"를 계획했다. 비용 없이 원인을 먼저 봤더니, 병목은 사실 고르기가 아니라 추출이었다.

- **근거 문장이 사실로 뽑히지 않았다.** M7에서 근거가 검사에 들어가지 않은 10개는 모두 근거 문장이 처음부터 사실로 저장되지 않았다. 고르는 방법을 바꿔도 찾을 수 없다.
- **긴 화에서 추출이 성기다.** 1,000자당 뽑힌 사실 수가 원고 종류마다 크게 다르다.
  - 합성 원고(M0-A, 화당 약 1,200자): 약 10개
  - 실제 원고(화당 약 5,000자): 약 3개
  - 한 화를 통째로 보내면, 화 길이와 상관없이 비슷한 수만 뽑는 것으로 보인다.

## 2. 시범 측정 (2026-10-25, 작가 확인 뒤)

M7에서 근거가 빠진 10개 오류의 근거 화 8개를 약 1,500자 조각(4개씩)으로 나눠 다시 추출했다. 프롬프트(`extract-1`)는 그대로 쓰고, 인용 확인은 화 전체에서 했다.

| | 지금 (한 번에) | 나눠서 |
|---|---|---|
| 화당 사실 수 (8화 평균) | 17.6 | 34.8 |
| 근거 문장이 사실로 잡힌 오류 | 0 / 10 | **5 / 10** |
| 인용을 못 찾아 버린 사실 (8화 합계) | – | 11 |

- 비용: 토큰 기반 어림 $0.022.
- Costs API 확인값: 실행 직후 $0.0019 늘었다. 하루 단위 집계라 반영이 늦을 수 있어, 다시 확인해 보고서에 적는다.
- 아직 잡히지 않은 5개는 장소("길드 바로 앞의 콜로세움"), 일과표 한 줄, 서클 표기("수영장(4서클)") 같은 것이다. 짧은 표기나 상태창 줄은 나눠도 사실로 잘 뽑히지 않는다.

## 3. 범위

**포함**

- **나눠 추출 (제품)**: 화의 보이는 본문이 `EXTRACT_CHUNK_CHARS`(약 1,500자)보다 길면, 빈 줄(없으면 줄 끝)에서 끊어 조각마다 추출하고 합친다.
  - 인물·대상: 이름이 같으면 하나로 합치고 별칭을 모은다.
  - 사실: 모두 모은다. 인물·속성·값·인용이 모두 같은 것은 하나만 남긴다.
  - 요약: 조각 요약을 차례로 잇는다.
  - 인용 확인과 줄 주소는 화 전체 기준이다 (지금과 같다).
  - 조각은 화 안에서 동시에 보내지 않는다. 화끼리의 동시 실행(2개)은 그대로다.
  - 1,500자보다 짧은 화는 지금과 같다. 합성 원고(M0-A, 약 1,200자)의 결과는 바뀌지 않는다.
- **예상 비용**: 분석 예상 비용에 조각 수를 반영한다.
- **측정**: M7 복사본(오류 20개)을 새로 복사해 265화를 모두 나눠 추출하고, 같은 20화를 검사해 M7과 비교한다.
- **분석 결과의 표시**: 분석 결과에 나눠 추출했는지(조각 수)를 남긴다. 이미 저장된 분석은 다시 분석하지 않는다 (작가가 원할 때 [남은 화 분석]이나 다시 분석으로 바꾼다).

**제외**: 프롬프트 수정, 인물이 아닌 대상으로 사실 고르기(필요하면 다음 단계), 모델 변경.

## 4. 성공 기준 (실행 전에 고정)

| 항목 | 기준 | 근거 |
|---|---|---|
| 근거 retrieval (심은 오류 20개) | ≥ 15 / 20 (M7 10/20) | 시범에서 빠진 10개 중 5개가 잡혔다 |
| Recall (사람 판정, 확신도 기준값 적용 뒤) | ≥ 50% (M7 30%) | M7 계획의 60%는 못 미쳤다. 한 단계에서 올릴 현실적인 목표 |
| 화당 오탐 (사람 판정) | ≤ 1 | 사실이 늘면 오탐도 늘 수 있다 |
| 추출 인용 보존 | ≥ 90% | M3 기준 |
| 비용 (Costs API로 확인) | 이번 단계 ≤ $1.5 | 토큰 어림 약 $1.2 (아래) |
| 합성 원고 영향 | M0-A 화는 나뉘지 않아 결과가 같다 | 단위 테스트로 확인 |

## 5. 예상 비용 (토큰 기반 어림)

| 작업 | 어림 |
|---|---|
| 265화 나눠 추출 (시범 화당 약 $0.0028) | 약 $0.75 |
| 20화 검사 (사실이 약 2배 → 검사도 약 2배) | 약 $0.45 |
| 합계 | 약 $1.2 (한도 $1.5) |

남은 전체 한도는 Costs API 기준 약 $4.33다 (2026-10-25, 사용 $5.67 / $10). 실행 전후로 Costs API로 확인해, 그 차이를 이 단계의 비용으로 적는다.

## 8. 위험

- **비용이 오른다**: 긴 화의 분석 비용이 약 2배, 사실이 늘어 검사 비용도 약 2배가 된다. 작가가 긴 연재를 다 분석하면 체감된다. 보고서에 화당 비용을 적는다.
- **오탐이 늘 수 있다**: 사실이 많아지면 모델이 비교할 것도 많아진다. 화당 오탐을 기준에 넣었다.
- **조각 경계의 문맥 손실**: 한 장면이 두 조각으로 나뉘면 주어나 대상이 앞 조각에만 있을 수 있다. 빈 줄에서 끊어 줄이고, 결과에서 따로 본다.
